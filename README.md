# Social Media TAG CLO VOR

Alojamiento TEMPORAL de artes para publicar por API en Instagram y Facebook. Repo público: todo lo que entra aquí es visible.

Carpetas: `TAG` (Tagnara) · `CLO-COL` (Clovai Colombia) · `CLO-US` (Clovai US) · `VOR` (Vortech).

Regla: un arte entra aquí SOLO cuando hay orden de publicarlo. Tras publicar y verificar, se borra de aquí. El original se conserva en `entregables/` del repo privado.
